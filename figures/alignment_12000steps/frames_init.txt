Nearest vocabulary token for each 100 ms frame of three test utterances before training (reference text above each panel). Bar height is the cosine to the nearest token (0.10-0.16); runs of frames with the same nearest token are labelled, and green marks a token that is a spoken word. The nearest tokens are arbitrary strings (' hydr', ' pathway') and only one frame in the three utterances hits a spoken word, by chance.
